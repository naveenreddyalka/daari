# Get started

Pick the shortest path for your setup.

| Path | Time | Outcome |
|------|------|---------|
| [Install](install.md) | 5 min | daari on your machine (pip, Docker, or Homebrew) |
| [Quickstart](quickstart.md) | 5 min | `curl` hits L0 on the second request |
| [First client](first-client.md) | 5–15 min | Cursor or OpenAI SDK talking to daari |

**Prerequisites:** Python 3.12 (source install) or Docker. For local inference, [Ollama](https://ollama.com) with `llama3.2:3b` (or use Docker Compose, which pulls it).
